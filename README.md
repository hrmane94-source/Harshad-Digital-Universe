## 🚀 Quick Start & Development

### 1. Prerequisites
- **Node.js:** v18+ (Tested on v24)
- **Package Manager:** npm

### 2. Installation
```bash
git clone https://github.com/hrmane94-source/harshad-digital-universe.git
cd harshad-digital-universe
npm install
```

### 3. Environment Configuration
Copy `.env.example` to `.env`:
```bash
cp .env.example .env
```
*(See [SUPABASE_SETUP.md](./SUPABASE_SETUP.md) for configuring your free Supabase instance).*

### 4. Start Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 5. Run Tests & Production Build
```bash
# Run automated test suite (11 passing tests)
npm test

# Run TypeScript check and production build
npm run build
```

## 🔒 Security & Data Integrity Principles

- **No Fabricated Data:** No unverified metrics, visitor counts, fake percentages, or unearned credentials exist.
- **Prototypes Distinguished:** Hackathon demonstration datasets are clearly distinguished from operational hospital records.
- **Row Level Security (RLS):** Database-level access rules guarantee that private drafts, tasks, and reflections are accessible *only* to `hrmane94@gmail.com`.
- **Zero Secrets in Frontend:** Privileged service-role keys are never embedded in client bundles.
